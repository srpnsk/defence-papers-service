# Компилятор (конвертер)

Это микросервис с единственным эндпоинтом. 
Принимает адрес html документа в файловой системе, возвращает битовый поток готового документа (docx/pdf).

## Сделано:

1. Сама логика сервиса
2. Некоторые юнит и интеграционные тесты (смешанный тип тестов, потому что работа функций полностью завязана на сторонних библиотеках)
3. main файл, с которого начинается работа
