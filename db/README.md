## Комментарий

Не делайте лишних ограничений и проверок ввода пока не протестируете основной функционал

Формы могут быть заполнены не до конца, но *должны быть сохранены в БД*, то есть ограничения целостности в базе данных вы не должны делать (реализуйте все проверки в коде!)
